# পাঠ ৩: Data Type ও Built-in Function

## ধরন(value)

কোনো মানের Data Type জানায়।

উদাহরণ:

```bb
সংখ্যা বয়স = 34
দেখাও ধরন(বয়স)
```

প্রত্যাশিত ফল: `integer`

সমর্থিত Type পরিচয়:
- integer: পূর্ণসংখ্যা
- float: দশমিক সংখ্যা
- string: লেখা
- boolean: সত্য বা মিথ্যা
- null: অনুপস্থিত মান

## দৈর্ঘ্য(value)

String-এর Unicode code point সংখ্যা ফেরত দেয়।

উদাহরণ:

```bb
সংখ্যা নাম = "বাংলাদেশ"
দেখাও দৈর্ঘ্য(নাম)
```

নোট: দৈর্ঘ্য() বর্তমানে শুধু String গ্রহণ করে।
এটি দৃশ্যমান অক্ষর বা grapheme cluster-এর সংখ্যা নয়।

## অনুশীলন
১. একটি Integer তৈরি করে ধরন() ব্যবহার করুন।
২. একটি দশমিক সংখ্যা তৈরি করে ধরন() ব্যবহার করুন।
৩. একটি String তৈরি করে দৈর্ঘ() ব্যবহার করুন।
