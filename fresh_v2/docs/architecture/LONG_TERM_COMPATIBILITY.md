# Long-Term Compatibility

- Versioned language specification.
- Versioned bytecode format.
- Backward compatibility tests.
- Migration utilities.
- Reproducible release artifacts.
- Archived documentation and source.
- Cryptographic hashes for release verification.
- Multiple runtime backends.
- Explicit deprecation policy.
- Documented platform dependencies.

Long-term preservation is an engineering goal, not a guaranteed lifespan.
